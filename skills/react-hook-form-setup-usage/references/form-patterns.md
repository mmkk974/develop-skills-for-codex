# フォーム実装パターン

## 1. 標準パターン

1. スキーマを定義する（例: Zod）。
2. `useForm` で `resolver` と `defaultValues` を設定する。
3. `register` または `Controller` で入力を接続する。
4. `handleSubmit` で送信処理を実装する。
5. 成功時/失敗時の表示を分ける。

## 2. `Controller` を使う基準

- 外部UIライブラリの入力部品
- 値変換が必要な入力
- `ref` の受け渡しが難しい入力

## 3. エラーハンドリング方針

- フィールド単位エラー: 該当入力の近くに表示する。
- フォーム全体エラー: 送信ボタン付近に表示する。
- サーバーエラー: 再試行導線を併記する。
