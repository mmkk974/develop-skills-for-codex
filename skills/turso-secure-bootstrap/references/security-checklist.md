# Security Checklist

## Secret Handling

- [ ] `.env*` がGit追跡されていない（`.env.example` は除く）。
- [ ] トークン全文をログ出力しない仕組みにしている。
- [ ] CIのシークレット設定に平文トークンを直接貼る運用を禁止している。
- [ ] 漏洩時の失効手順が定義済みである。

## Token Design

- [ ] ランタイム用トークンとマイグレーション用トークンを分離している。
- [ ] ランタイムに管理者権限相当トークンを使っていない。
- [ ] トークンの有効期限またはローテーション頻度を決めている。

## Access Verification

- [ ] ランタイム資格情報で読取が成功する。
- [ ] ランタイム資格情報でDDL操作が拒否される。
- [ ] マイグレーション資格情報で必要なDDLのみ実行できる。

## Repo / CI Hygiene

- [ ] `.env.example` はプレースホルダのみで実値がない。
- [ ] CIログで環境変数のマスク設定を有効化している。
- [ ] チーム共有時にトークンを貼らないルールを明文化している。
