# 運用ガイドライン

## 1. クラス設計

- レイアウト、タイポグラフィ、色の責務を混在させすぎない。
- 同一パターンを3回以上書く場合はコンポーネント化を検討する。
- 条件分岐を伴う class は `cn` で管理する。

## 2. デザイントークン

- `:root` に主要トークンを定義し、ハードコード値を減らす。
- 画面ごとの独自値は最小化する。
- テーマ切り替えがある場合は `data-theme` か `class` で分離する。

## 3. 保守性

- 1ファイル内に長大な class 文字列を増やしすぎない。
- 使われない class や不要なカスタム CSS は削除する。
