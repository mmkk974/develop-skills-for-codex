# 差分同期ルール（SDD組み込み）

## 1. spec 同期

1. 変更要求 `CRQ-*` に対応する差分要件を `REQ-*` として追加する。
2. 既存 `REQ-*` を変更する場合、変更前後を明示する。
3. 受け入れ基準を差分更新する。

## 2. plan 同期

1. 差分要件に対応する `PLN-*` を追加する。
2. 影響を受ける既存設計を更新し、理由を記録する。
3. テスト戦略とロールバック方針を再評価する。

## 3. task 同期

1. 差分設計に対応する `TSK-*` を追加する。
2. 不要化したタスクは「停止」として理由を残す。
3. 依存関係を再計算する。

## 4. imple 同期

1. 実装済み箇所に再作業が必要なら追補タスクを作成する。
2. 差分実装とテスト結果を追記する。
3. `REQ -> PLN -> TSK -> 実装/テスト` のトレースを更新する。

## 5. 最終再判定

- 差分同期後に `spec-driven-development/references/phase-gates.md` を再判定する。
- fail がある場合は、最初の fail フェーズへ戻して再実行する。
