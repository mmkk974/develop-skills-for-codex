# レビューチェックリスト

## 1. 正しさ

- 要件と実装が一致しているか
- 境界条件、null/empty、例外系を扱っているか
- 仕様逸脱や後方互換性破壊がないか

## 2. 安全性

- 認可/認証の欠落がないか
- 機密情報の露出リスクがないか
- 入力値検証やサニタイズが適切か

## 3. 性能

- 不要な再計算やN+1がないか
- キャッシュ戦略が適切か
- フロントエンドで不要な再レンダリングがないか

## 4. 保守性

- 命名と責務分離が適切か
- 重複実装がないか
- テストしやすい構造か

## 5. テスト

- 変更箇所に対するテストがあるか
- 失敗ケースのテストがあるか
- 回帰を検出できるテスト粒度か
