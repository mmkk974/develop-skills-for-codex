# コンポーネント運用ガイド

## 1. 導入方針

- 使用予定のあるコンポーネントだけ追加する。
- 追加後は props とスタイル拡張方針を明記する。
- 過剰なラップコンポーネントを作らない。

## 2. 拡張方針

- デザイン差分は `variant` または `className` で拡張する。
- アクセシビリティ属性を削除しない。
- ダイアログやドロップダウンは状態管理責務を分離する。

## 3. フォーム連携

- `Input`, `Select`, `Textarea` は React Hook Form の `Controller` 必要性を判断する。
- バリデーション表示とエラーメッセージの位置を統一する。
