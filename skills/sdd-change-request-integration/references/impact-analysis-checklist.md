# 影響分析チェックリスト

## 1. 要件影響

- [ ] どの `REQ-*` が追加/変更/削除されるか整理した
- [ ] 既存受け入れ基準への影響を整理した

## 2. 設計影響

- [ ] どの `PLN-*` が追加/変更されるか整理した
- [ ] 非採用案の再評価が必要か判断した

## 3. 実装影響

- [ ] どの `TSK-*` が追加/変更/停止されるか整理した
- [ ] すでに実装済み箇所への差分を整理した

## 4. テスト影響

- [ ] 追加すべきテストを特定した
- [ ] 既存テストの更新要否を判断した

## 5. リスク/優先度

- [ ] リリース影響を評価した
- [ ] 互換性リスクを評価した
- [ ] 優先度（高/中/低）を決定した

判定方法: 全チェックで `pass`。未達があれば `fail`。
